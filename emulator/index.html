How to use

  1. Pick a system from the dropdown above — 35 systems across Nintendo, Sony, Sega, Atari, arcade, computers and more.
  2. Upload your ROM file using the file picker. Your ROM is loaded directly from your device — it is never sent to any server. Some systems (PS1, Saturn, PC-FX, 3DO, Amiga) also need a BIOS file you provide yourself.
  3. Click Load Game. The emulator boots in the stage below. Use your keyboard to play (arrow keys, Z/X or A/S, Enter = Start, Shift = Select) or connect a gamepad and press a button.
  4. Full screen: hover the game and click the full-screen icon in the emulator toolbar, or press F while the game has focus.
  5. Save states: open the emulator menu (gear icon) to save or load state at any time. Save states are stored in your browser’s local storage.
